# STAT 159 Homework 3: Tennis Career Python Package

This repository contains a Python package for retrieving, processing, and visualizing professional tennis players' career match data from Tennis Abstract.

## Features

The package is being developed to provide two main functions:

1. Retrieve and clean career match data for a specified tennis player.
2. Generate a scatter plot showing the player's age, the age difference between the player and their opponents, and match outcomes.

## Installation

Once the package is complete, it can be installed directly from GitHub:

```bash
pip install git+https://github.com/UCB-stat159-f26/hw03-2-darrensolichin.git
```
